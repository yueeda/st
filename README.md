# ST (Summa Theologiae)

Japanese translation project of Thomas Aquinas' *Summa Theologiae*.

This repository contains the LuaLaTeX sources and generated PDF files for the Japanese translation of the *Summa Theologiae*.

## Feedback Welcome

This translation is an ongoing scholarly project, and I warmly welcome constructive feedback.

If you notice typographical errors, formatting problems, or possible translation issues, please feel free to open a GitHub Issue or submit a Pull Request. Thoughtful suggestions, corrections, and scholarly discussion are greatly appreciated.

If you prefer, you are also welcome to contact me by email: <ueeda@keio.jp>

Thank you for helping improve the quality and accuracy of this project.
