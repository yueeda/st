# ST (Summa Theologiae)

Japanese translation project of Thomas Aquinas' *Summa Theologiae*.

This repository contains the LuaLaTeX sources and generated PDF files for the Japanese translation of the *Summa Theologiae*.

## Contents

- LaTeX sources
- Generated PDF files

## Build

```bash
./rebuild-all.sh
```
